# 🌎 地球破壊オンライン (v2.0 リファクタリング版)

セキュリティ、パフォーマンス、およびデータ拡張性を本番環境（Production）レベルに引き上げたモダンアーキテクチャ版です。

## 🛠️ 改善されたヤバいポイント（テクニカルスタック）

1. **ゼロ・トラスト（チート対策）の徹底**
   - クイズの正解データ、ダメージアルゴリズム、コインの付与ロジックをすべて `api/server.js`（サーバーサイド）に隠蔽。
   - クライアントからの改ざんリクエストを完全に無効化。
2. **ステート（状態）駆動型アーキテクチャ**
   - スパゲッティ化していたベタ書きDOM操作を廃止し、`GameApp.state` による一元管理へ移行。
3. **1000人対戦のレンダリング最適化**
   - 毎回1000人分のDOMを再生成してブラウザをクラッシュさせる悪癖を排除。初回の `DocumentFragment` 一括注入と、以降はターゲット要素のクラス属性（`classList`）のみを変更するピンポイント更新（O(1)〜O(N)の最小化）を達成。
4. **拡張性の確保**
   - ハードコードされていた問題データを `QUIZ_BANK` としてサーバー側に集約。今後データベース（MongoDBやPostgreSQL等）へ即時移行可能な設計。

## 🚀 GitHub & Vercel デプロイ手順

### 1. フォルダ構成の変更
VercelのServerless Functionsの仕様に合わせるため、デプロイ前にGitHubリポジトリを以下の構成に配置してください。
```text
├── index.html
├── README.md
└── api/
    └── server.js  <-- (server.jsをapiフォルダの中に移動)
```

### 2. Vercelへのデプロイ
1. GitHubに上記構成でプッシュします。
2. [Vercel Dashboard](https://vercel.com) を開き、**「Add New」->「Project」** を選択。
3. 対象のリポジトリをインポートします。
4. **Environment Variables（環境変数）** の設定項目を開き、以下を設定します。
   - `GAME_SECRET_KEY`: 任意の強力な文字列（チート検証用ハッシュのソルトになります）
5. 「Deploy」ボタンを押せば、数秒で世界中に公開されます。
